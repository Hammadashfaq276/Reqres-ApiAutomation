This project is an API Automation Testing Framework developed to automate the ReqRes public REST APIs using Java and Rest Assured.

The framework validates HTTP methods, request/response data, status codes, and API behavior, following real-world API testing practices.
This project is created for learning, practice, and SDET portfolio purposes.

🛠️ Tech Stack & Tools

Programming Language: Java

API Automation Tool: Rest Assured

Test Framework: TestNG

Build Tool: Maven

Data Format: JSON

Version Control: Git & GitHub

IDE: IntelliJ IDEA / Eclipse

📂 Project Structure
ReqRes-API-Automation
│
├── src/main/java
│   ├── base           → Base request & common utilities
│   ├── utils          → API helpers, config utilities
│
├── src/test/java
│   ├── tests          → API test classes
│
├── pom.xml
└── README.md

🔗 APIs Automated (ReqRes)

The following ReqRes APIs are automated:

GET – List Users

GET – Single User

POST – Create User

PUT – Update User

PATCH – Partial Update

DELETE – Delete User

✅ Key Features

✔ REST API automation using Rest Assured
✔ Validation of status codes and responses
✔ Request & response body assertions
✔ TestNG-based execution
✔ Reusable request specifications
✔ Maven dependency management
✔ Clean and maintainable code structure
✔ GitHub version control

🧪 API Validation Strategy

Validate HTTP status codes

Validate response body fields

Validate response time

Validate headers and content type
